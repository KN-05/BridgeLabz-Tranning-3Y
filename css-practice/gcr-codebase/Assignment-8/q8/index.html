Box-Sizing Comparison

How content-box and border-box affect total element size

content-box

This box uses the default box-sizing: content-box. Width and padding are added together, so the box appears wider than its declared 250px width once padding is included.

border-box

This box uses box-sizing: border-box. Padding is included inside the declared 250px width, so the box stays exactly the size you set.
